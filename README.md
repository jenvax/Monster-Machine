# Monster Machine

A playful random character generator for artists making whimsical spooky monsters.

## Run Locally

This first version is a static app. From the project folder, run:

```bash
python3 -m http.server 5173
```

Then open `http://localhost:5173`.

## Editing Prompts

All prompt options live in `src/options.js`.

The physical monster prompts are in `MONSTER_CATEGORIES`. The wildcard prompt is in `MAYHEM_CATEGORY`.
